# 数据模型

[English](Data-Model) | **简体中文**

## 工作区存储

`$DSH_HOME/storages/workspace-settings/settings.json`：

```json
{
  "version": 1,
  "workspaces": {
    "<规范化路径>": {
      "path": "C:\\Projects\\demo",
      "workspaceId": "workspace-…",
      "preset": "creative",
      "permission": "workspace-write",
      "model": {
        "provider": "deepseek-official",
        "model": "deepseek-flash",
        "reasoningEffort": "max"
      },
      "transcriptView": "standard",
      "collapseTiming": "completion",
      "updatedAt": "2026-10-27T00:00:00.000Z"
    }
  },
  "sessions": {
    "session-…": { "preset": "creative", "permission": "workspace-write", "at": 1761523200000 }
  }
}
```

### 记录字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `path` | string | 工作区原始路径（用于 UI 展示） |
| `workspaceId` | string? | 仅供参考；匹配使用路径 |
| `preset` | string \| null | Agent 预设 id；`null` 表示跟随全局 |
| `permission` | string \| null | 权限预设键；`null` 表示跟随全局 |
| `model` | object \| null | `{ provider, model, reasoningEffort? }`；`null` 表示跟随全局 |
| `transcriptView` | `compact` \| `standard` \| `detailed` \| `verbose` \| null | 工作步骤展示；`null` 跟随全局 |
| `collapseTiming` | `completion` \| `next-input` \| null | 收起时机；`null` 跟随全局 |
| `updatedAt` | ISO string | 最后一次接受写入的时间 |

每个维度都可独立为空；所有字段都为 `null` 的记录会被删除。

### 键与规范化

map 键是规范化路径：

- `/` 与 `\` 等价，末尾分隔符被去掉；
- Windows 路径比较前转小写；
- 匹配会话时使用会话存储的 `cwd`。

重命名工作区不改变键。移动目录会产生新键，旧记录保留到手动删除。两个相同路径的工作区共享
同一条记录。

### 会话缓存

按 session id 保存的 `lastApplied` 值用于区分“用户在会话内显式选择”和“插件自己应用的值”。
超过 7 天、以及超过 800 条后最旧的记录会被清理。丢失该段只会影响后续替换的保守程度，不会
影响 Session 状态正确性。

## Chat 基线

`localStorage["dsh-workspace-settings:chat-baseline:v1"]`：

```json
{ "transcriptView": "standard", "collapseTiming": "completion" }
```

这是用户自己的全局 Chat 展示值，在插件首次应用工作区覆盖前捕获。它按浏览器 profile 保存；
清除该键会在下次加载时重新捕获当前值。

## 校验

- 容忍 `version` 差异；未知结构会被替换为空存储；
- 当前 catalog 不再提供的预设 / 权限 / 模型 / 强度会从记录中丢弃；
- 所有写入经过一条串行队列和临时文件原子重命名；写入失败保留旧文件。
