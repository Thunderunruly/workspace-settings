DSH 工作区设置是 **DeepSeek Harness（DSH）** 的工作区级设置插件。每个工作区可以保存自己的
Agent 模式、权限预设、模型、推理强度、Chat 工作步骤展示级别与收起时机；在该工作区新建的
会话直接使用这些值，而会话内的手动修改仍然优先。

- 仓库：[Thunderunruly/workspace-settings](https://github.com/Thunderunruly/workspace-settings)
- 问题反馈：[Issues](https://github.com/Thunderunruly/workspace-settings/issues)
- 版本：[Releases](https://github.com/Thunderunruly/workspace-settings/releases)
- English docs: [English Wiki](Home) ·
  [README](https://github.com/Thunderunruly/workspace-settings/blob/main/README.md)

## 快速开始

```sh
dsh plugin --profile <profile> add dsh-workspace-settings
```

重载一次 DSH 窗口，悬停工作区行，点 `...`，选择 **工作区设置**。想用本地目录的话，也可以
在桌面端 **设置 → 插件 → 添加插件 → 本地 bundle** 中安装克隆目录。升级与卸载见
[安装](安装)。

## 功能

- **工作区菜单入口**：工作区行 `...` 菜单新增 **工作区设置**，位于重命名 / 删除工作区上方；
  右键工作区行会打开同一个官方菜单。
- **工作区设置页**：设置 → 工作区设置 列出所有工作区及其覆盖项与编辑入口。
- **六项按工作区默认值**：模式、权限、模型、强度、工作步骤展示、收起时机。每一项都可选择
  跟随全局。
- **新会话生效**：新建或复用的空白会话会收到工作区默认值；会话内显式选择优先。
- **官方 UI**：使用官方 `Menu` / `Modal` / `Button` / `Input`，行几何与通用设置一致；修改
  立即生效，没有保存 / 取消。
- **纯本地**：数据保存在 DSH home 下的一个 JSON 文件；无遥测、无网络请求。
