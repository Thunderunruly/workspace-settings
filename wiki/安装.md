# 安装

[English](Installation) | **简体中文**

## 环境要求

- **DeepSeek Harness（DSH）**，需支持 Web UI 与插件；开发与验证基于 DSH `0.2.1-rc.3`
  桌面端 profile。
- 需要 Chromium 内核的 DSH Web UI。插件注册的是客户端槽位，纯 CLI 组合不会显示界面。
- 插件包为 ESM（`"type": "module"`），运行时从宿主模块表加载 `react` 与
  `@deepseek-ai/dsh-client-ui-primitives`，不打包依赖。
- `node` 仅离线检查需要；普通使用不需要安装 Node。

插件尚未发布到 npm，请从本仓库安装。

## 从本地目录安装

```sh
git clone https://github.com/Thunderunruly/workspace-settings.git
```

### 桌面端

打开 **设置 → 插件 → 添加插件 → 本地 bundle**，选择克隆下来的目录。桌面端 profile 由
Electron 应用管理，请通过应用内插件管理器安装，不要手改 `cordis.patch.yml`。

### CLI profile

把目录作为 linked 依赖加入 profile，让 bundle patch 自动插入插件行：

```sh
dsh plugin --profile web add file:/本目录绝对路径
```

安装后重载一次 DSH 窗口，让客户端 bundle 进入启动图；此后客户端改动支持热加载。

## 验证安装

1. 悬停侧边栏工作区行，`...` 菜单中出现 **工作区设置**，位于重命名 / 删除工作区上方；
2. 侧边栏设置导航中出现 **工作区设置** 页面；
3. 页面列出所有工作区，每行有「编辑」按钮与覆盖摘要。

第一次配置见 [使用指南](使用指南)。

## 升级

1. 在克隆目录执行 `git pull`；
2. 通过插件管理器重新安装 / 刷新 bundle；
3. 重载 DSH 窗口。Host 侧改动需要重新启用插件行。

## 卸载

在插件管理器中移除 bundle，或从 profile 删除 linked 依赖；重载后客户端槽位、样式与设置页
都会消失。已保存的配置仍在
`$DSH_HOME/storages/workspace-settings/settings.json`，删除该文件才会清空。

## 排错

安装后入口没出现时，先完整重载窗口（不要只切换面板），并检查浏览器控制台中的
`[workspace-settings]` 日志。更多见 [常见问题](常见问题)。
