# 版本记录

[English](Releases) | **简体中文**

## 版本策略

语义化版本。插件面向 DSH `0.2.1-rc.3`，manifest 声明
`engines.dsh = ">=0.2.1-rc.3 <0.3.0-0"`。若 DSH 集成发生破坏性变化，即使插件行为未变也
可能需要发布对应版本。

## v1.0.0 — 2026-10-27

首个公开版本。

### 功能

- 按工作区保存会话默认值：Agent 模式、权限预设、模型、推理强度。
- 按工作区保存 Chat 展示：工作步骤展示与收起时机。
- 每个工作区行官方 `...` 菜单（及右键）入口，外加设置页。
- 官方 UI 原语（`Menu`、`Modal`、`Button`、`Input`）与设置行几何；修改立即生效，无保存 /
  取消。
- 内置预设与权限显示产品文案（不显示机器键）；自定义预设保留自身名称。
- 空白/新会话继承默认值，并保留会话内显式选择。
- 模型仅覆盖首请求，之后会话内模型选择器继续生效。
- 本地 JSON 存储与原子写入；无网络、无遥测。
- 离线宿主检查（`node --test test/host.check.mjs`）。

### 安装

本版本从仓库目录安装：

```sh
git clone https://github.com/Thunderunruly/workspace-settings.git
```

然后在桌面端插件管理器（本地 bundle）或 CLI profile
（`dsh plugin --profile web add file:/路径/workspace-settings`）中安装，并重载一次窗口。
见 [安装](安装)。

### 已知限制

- DSH 0.2.1 没有原生工作区菜单槽位；菜单由官方 `Menu` 原语重新渲染。
- 模型 / 强度只作用于首个模型请求。
- 工作步骤展示 / 收起时机通过官方全局 Chat 偏好在工作区会话激活时切换（没有 per-session
  API）。
- 不是 DeepSeek 官方产品。

## 升级说明

目前不需要迁移。存储在加载时会归一化；不再可用的预设 / 权限 / 模型值会被掩码，直到它们
重新可用。
