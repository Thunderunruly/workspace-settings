# 使用指南

[English](Usage) | **简体中文**

## 打开设置

两个入口进入同一个编辑器：

1. **工作区行菜单**：悬停侧边栏工作区行，点 `...`，选择 **工作区设置**；右键该行会打开同一个
   官方菜单。
2. **设置页**：设置 → **工作区设置** → 任意工作区的 **编辑**。

对话框使用宿主官方行几何：左侧标题与说明，右侧带 chevron 的填充选择器。修改立即写入，没有
保存 / 取消按钮；用 `×`、Escape 或点击遮罩关闭都会保留已生效的修改，只有失败时才显示错误。

## 六项默认值

| 字段 | 可选值 | 作用 |
| --- | --- | --- |
| **模式** | 任意已安装 Agent 预设，或全局默认 | 新会话使用的 Agent 预设 |
| **审查与权限** | 任意已配置权限预设，或全局默认 | 记录到新会话的沙箱 + 审批组合 |
| **模型** | 任意可路由模型，或全局默认 | 会话首个请求使用的模型 |
| **强度** | 所选模型的推理强度 | 首个请求使用的强度；未选模型时禁用 |
| **工作步骤展示** | 简洁 / 标准 / 详细 / 完全展开，或全局值 | 该工作区会话激活时 Chat 过程细节的级别 |
| **工作步骤收起时机** | 回答结束后 / 下次有新消息时，或全局值 | 完成后的工作步骤何时折叠 |

「跟随全局默认」会在括号里显示当前全局值，不必打开通用设置就能看到实际生效值。

## 继承规则

当会话在该工作区创建（或复用空白会话）时：

- **模式**：仅在会话尚未开始对话时通过官方 Agent 预设切换接口应用。
- **权限**：通过官方权限预设接口应用，成为正常的 Session 事件。
- **模型 + 强度**：作为首个请求的覆盖；从会话第二次模型请求开始，会话自己的模型选择器重新
  生效。
- **工作步骤展示 / 收起时机**：该工作区会话激活期间跟随工作区值，离开后恢复全局基线。

已经开始对话的会话不会被改写；子代理会话与分叉会话会跳过。空白会话中的显式选择（模式、
权限、模型）会被保留：插件只替换仍等于全局默认、或等于上次由工作区应用的值。

## 典型流程

1. 打开工作区行菜单 → **工作区设置**。
2. 选择该项目要用的模式、权限、模型与强度。
3. 如果该项目希望与别的项目不同的展示方式，再选择工作步骤展示与收起时机。
4. 关闭对话框，在该工作区新建会话——会话头部、输入区与 Chat 会使用工作区的值。
5. 需要临时调整时直接使用会话内选择器，后续新建不会被它覆盖。

## 插件不会改变什么

- 不会重写已存在的对话。
- 不会为工作步骤展示 / 收起时机写 Session 事件。
- 不会替换会话内选择器；会话内选择始终是最终决定。
- 没有工作区概念的设置（外观、语言、链接打开方式、性能与用量、隐私选项）保持全局。
