# 常见问题

[English](FAQ) | **简体中文**

## 安装后看不到入口

先完整重载 DSH 窗口（不要只切换面板），客户端 bundle 会在重载后进入启动图。然后检查：

- 工作区行的 `...` 菜单中有 **工作区设置**；
- 设置导航中有 **工作区设置**；
- 浏览器控制台没有 `[workspace-settings] cannot mount` / `host primitives missing` 日志。

如果控制台提示缺少宿主原语，说明当前 DSH 版本低于所需的 `Menu`/`Modal`/`Button`/`Input`
版本，请升级 DSH。

## 为什么工作区 `...` 菜单变了？

DSH 0.2.1 没有工作区菜单项的扩展槽位。要在这一个菜单里增加条目，插件会识别文档化的工作区
行、接管菜单按钮，并用**官方 `Menu` 原语**渲染菜单，在保留重命名/删除（调用公开工作区服务）
的同时加上工作区设置行。见 [架构](架构)。

## 为什么没有保存按钮？

工作区设置与通用设置保持一致：每次选择立即写入。关闭对话框会保留已生效的修改，只在失败时
显示错误。见 [使用指南](使用指南)。

## 我给工作区设置了模式/权限，但新会话没有生效

请检查：

- 会话确实属于该工作区（你配置的那一行）；
- 会话创建时仍是空白——已经开始对话的会话不会被改写；
- 预设仍存在且未损坏；损坏的预设会在选择器中带警告，不会被应用；
- 你没有在那个空白会话里显式换过别的模式。显式选择会被保留，插件只替换仍看起来是全局默认
  或上次工作区应用值的项。

## 已有会话里模型变回了全局模型

模型与强度只应用于新会话的**首个**模型请求；从第二次请求开始由会话自己的模型选择器决定。
这是刻意的：工作区默认值不应锁死整段对话的模型。

## 切换工作区会改变通用设置里的值

这是预期行为。工作步骤展示与收起时机是官方全局 Chat 偏好，没有 per-session API。插件在
配置过的工作区会话激活时切换它们，离开时恢复你的全局基线；在通用设置里修改全局值会更新
基线。见 [使用指南](使用指南#六项默认值) 与 [架构](架构#chat-展示偏好-watcher)。

## 下拉里显示 `standard` / `workspace-write` 而不是产品文案

内置预设与权限会映射为宿主产品文案（标准模式 / 工作区内修改 等）。**自定义**预设如果自带
名称会显示该名称；自定义权限预设如果配置的是机器风格名称会转成标题格式。若内置项仍显示
机器键，可能是宿主 catalog 没有发布名册——重载窗口并检查控制台。

## 如何重置某一个工作区？

打开它的编辑器，把每个字段改回 **跟随全局默认**。所有字段都跟随全局后，该工作区记录会被
删除。

## 如何全部重置？

停止 DSH，删除 `$DSH_HOME/storages/workspace-settings/settings.json`，或删除其中的单个
工作区条目。要重置 Chat 展示基线，清除浏览器 `localStorage` 键
`dsh-workspace-settings:chat-baseline:v1`。

## 重命名或移动工作区会怎样？

重命名保留设置（存储以路径为键，而不是标题）。移动目录会在新路径下生成新记录，旧记录保留
到手动删除。

## CLI/headless profile 能用吗？

宿主端可以加载，但设置界面是纯客户端的，CLI 组合不会显示入口。请使用 Web UI profile。

## 插件会联网吗？

不会。它只保存一个本地 JSON 文件，Chat 基线存在浏览器 `localStorage`，不包含任何遥测。
